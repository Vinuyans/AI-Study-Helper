## Setup Instructions
1. Clone the repository
2. Go to [Google's AI Studio](https://aistudio.google.com/app/api-keys) and generate a key
3. Create a `.env` file at the root of the `server` folder and write `API_KEY=[your api key]`
4. From `ai-study-helper` run `npm run install-packages`
5. Now run `npm run dev` to start running the application on at https://localhost:3000
